# Bubble Trio Pro — AdSense readiness checklist

This checklist is a project-maintenance guide, not a promise or guarantee of Google AdSense approval. The publisher must compare the live site and account against current official Google policies before applying or enabling ads.

## Current site status

- [x] Original Bubble Shooter game implementation and other original mini-games.
- [x] Useful, game-specific instructions, rules, scoring explanations, and FAQs on the homepage.
- [x] Working navigation to the game library, guide, About, Privacy, Cookie Policy, Terms, and Contact pages.
- [x] Clearly labelled empty ad placeholders with reserved minimum heights; no AdSense script or live ad request is loaded.
- [x] Responsive layout and separate advertisement containers.
- [x] Robots and sitemap routes.
- [ ] Private contact email or contact form: configure a real contact channel before launch if desired.
- [ ] Final proofread of every game on desktop and mobile.
- [ ] Test the deployed page and every policy link in a normal signed-out browser.
- [ ] Check that the production domain is canonical and that robots/sitemap URLs use that domain.
- [ ] Apply for AdSense using the domain and publisher account you actually control.
- [ ] Add real ad code only after approval/configuration; never paste a sample or invented publisher ID.
- [ ] If AdSense provides a publisher ID and an authorised-seller record is applicable, add the correct record to /ads.txt. Do not commit an example ID.
- [ ] Review actual advertising partners, privacy disclosures, and consent configuration before the first ad request.
- [ ] Where required for personalised ads in the EEA, UK, or Switzerland, configure a Google-certified consent management platform that integrates with the IAB TCF.
- [ ] Keep ad containers away from game buttons, category navigation, and other interactive elements; verify layout does not shift when ads load.
- [ ] Check the Google AdSense Policy Centre after review and address any site-specific findings.

## Important

Google assesses the complete live website and publisher account, not just the presence of policy pages or a word-count target. Policy pages must describe the actual implementation. Replace this checklist when settings, vendors, hosting, or ad behaviour change.
